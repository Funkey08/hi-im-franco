Why this works

• Layered, not literal — fans of Steins;Gate catch the divergence-meter format and CRT power-off instantly; everyone else just experiences "cool retro-terminal intro into a generative animation," no explanation needed.
• The reference does double duty — "Worldline β → α" isn't just fan-service, it's a legitimate (if playful) way to foreshadow "I'm exploring multiple career paths" before the user even reads your About section.
• Reuses work you already wanted — the Game of Life piece was already on your TODO; this just gives it a far more prominent, load-bearing role instead of a hidden footer easter egg.
• The manga wipe graduates from "gimmick intro" to "site-wide signature motif" — used consistently between sections, it starts to feel like an intentional design language rather than a one-off trick.

Feasibility & guardrails

• Frames 1–3 (CRT text + divergence ticker): plain CSS + a JS interval, no library, very cheap.
• Frame 4 (CRT collapse): a single CSS scaleY keyframe, cheap.
• Frames 5–6 (Game of Life): small canvas + ~100 lines of GoL logic, no dependency needed; seed pattern engineered offline so it's deterministic, not random noise.
• Frame 7 (manga wipe): CSS clip-path polygon animation, reusable as a shared transition component.
• Total runtime target: ~2.5–3s, with a visible "Skip →" from frame 1 onward, full animation disabled under prefers-reduced-motion, and a localStorage flag so it only plays once per browser session.
